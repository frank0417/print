静默打印、枚举打印机需要安装 PrintKit Native Host（Windows / macOS）。

下载地址

  • 本项目源码 / 代理 github.com/frank0417/print · 下载 ZIP
  • Node.js ≥ 18（必装） nodejs.org · 中文下载页
  • Google Chrome 下载 Chrome · Microsoft Edge 下载 Edge
  • PDFtoPrinter.exe（Windows 静默打印推荐） columbia.edu/~em36/pdftoprinter.html
  • SumatraPDF（Windows 备选） sumatrapdfreader.org

下载项目 ZIP 后解压，进入 native-host 目录执行下方安装脚本。 Windows 可将 PDFtoPrinter.exe 放到 native-host/bin/。

安装步骤

  1. 安装 Node.js ≥ 18 与 Chrome / Edge（见上方下载）
  2. 下载并解压本项目，打开 native-host 目录
  3. 按系统执行安装脚本：

macOS

cd native-host
chmod +x scripts/install-mac.sh
./scripts/install-mac.sh

Windows

cd native-host
powershell -ExecutionPolicy Bypass -File .\scripts\install-win.ps1

安装后扩展 ID 须为 memmopnlapcegennpipheiadaonehljd（重新加载已解压的 extension/）。

安装自检

node native-host/host.js --cli ping
node native-host/host.js --cli getPrinters
