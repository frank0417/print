请安装 PrintKit 一体化安装包

静默打印需要本地打印代理。请下载对应系统的一体化安装包（已内置 Node 运行时、打印代理、扩展；Windows 另含 PDFtoPrinter）。

一体化安装包下载

  • Windows 安装包 PrintKit-Setup-windows.zip
    解压后双击 Install-PrintKit.bat
  • macOS 安装包 PrintKit-Setup-macos.zip
    解压后运行 Install-PrintKit.command
  • GitHub Releases github.com/frank0417/print/releases · 源码仓库

安装包内已包含：Chrome 扩展、Native Host、Node.js 运行时；Windows 另含 PDFtoPrinter。安装后只需在 chrome://extensions 加载扩展目录即可。

安装步骤（安装包）

  1. 下载上方对应系统的 ZIP 并解压
  2. Windows：双击 Install-PrintKit.bat　／　macOS：运行 Install-PrintKit.command
  3. 在 chrome://extensions 开启开发者模式，加载已解压扩展：
    Windows：%LOCALAPPDATA%\PrintKit\extension
    macOS：~/Library/Application Support/PrintKit/extension
  4. 确认扩展 ID 为 memmopnlapcegennpipheiadaonehljd，然后点下方「重新检测」
