静默打印、枚举打印机需要安装 PrintKit Native Host（Windows / macOS）。

安装步骤

  1. 确认已安装 Node.js ≥ 18 与 Chrome / Edge
  2. 打开本仓库中的 native-host 目录
  3. 按系统执行安装脚本：

macOS

cd native-host
./scripts/install-mac.sh

Windows

cd native-host
powershell -ExecutionPolicy Bypass -File .\scripts\install-win.ps1

安装后扩展 ID 须为 memmopnlapcegennpipheiadaonehljd。 Windows 建议将 PDFtoPrinter.exe 放到 native-host/bin/。

安装自检

node native-host/host.js --cli ping
node native-host/host.js --cli getPrinters
