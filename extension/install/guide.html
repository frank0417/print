请安装 PrintKit 一键安装包

静默打印需要本地打印代理。请下载对应系统的一键安装包（已内置 Node 运行时、打印代理、扩展；Windows 另含 PDFtoPrinter），双击即可安装。

一键安装包下载

  • Windows 一键安装 PrintKit-Setup-windows.exe
    下载后双击即可安装（无需解压）
  • macOS 一键安装 PrintKit-Setup-macos.command
    下载后双击即可安装（首次可能需右键→打开）
  • 备用 ZIP Windows ZIP · macOS ZIP · 全部 Releases

安装包内已包含：Chrome 扩展、Native Host、Node.js 运行时；Windows 另含 PDFtoPrinter。安装程序会自动打开扩展页并复制扩展目录路径。

安装步骤

  1. 下载上方对应系统的一键安装文件
  2. Windows：双击 .exe　／　macOS：双击 .command
  3. 在 chrome://extensions 开启开发者模式，加载已解压扩展（路径已复制）：
    Windows：%LOCALAPPDATA%\PrintKit\extension
    macOS：~/Library/Application Support/PrintKit/extension
  4. 确认扩展 ID 为 memmopnlapcegennpipheiadaonehljd，然后点下方「重新检测」
