PrintKit 一键安装包（macOS）
============================

推荐：PrintKit-Setup-macos.command
  → 双击即可安装（无需解压）
  → 首次若被拦截：右键 → 打开

本包已内置：
  - PrintKit Chrome 扩展
  - 本地打印代理（Native Messaging Host）
  - Node.js 运行时（x64 + arm64，安装时自动选择）

ZIP 备用安装步骤
----------------
1. 解压本 ZIP
2. 双击 Install-PrintKit.command
3. 在 chrome://extensions：
   - 开启「开发者模式」
   - 「加载已解压的扩展程序」
   - 选择安装程序打开的扩展目录
4. 确认扩展 ID 为：memmopnlapcegennpipheiadaonehljd
