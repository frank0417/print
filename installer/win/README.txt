PrintKit Windows One-Click Setup
================================

Recommended: PrintKit-Setup-windows.exe
  -> Double-click to install (no unzip)

This ZIP fallback includes:
  Chrome extension, native print host, Node.js runtime, PDFtoPrinter.exe

Install (ZIP)
-------------
1. Download from GitHub Releases (do NOT re-zip via WeChat)
2. Extract to a short path, e.g. C:\PrintKit-Setup-windows
3. Double-click Install-PrintKit.bat
4. chrome://extensions -> Developer mode ON -> Load unpacked
5. Select the opened folder: %LOCALAPPDATA%\PrintKit\extension
6. Extension ID must be: memmopnlapcegennpipheiadaonehljd
